# iOS Family Controls onboarding — Arabic RTL wireframe

## Flow overview

```text
[1] لماذا نحتاج الإذن؟
        ↓
[2] منح إذن الرقابة
        ↓
[3] اختيار الحماية
        ├── قيود التطبيقات والفئات
        └── حماية النطاقات المدعومة
        ↓
[4] اختبار الحالة
        ├── الحماية مفعّلة
        ├── تم منح إذن الرقابة فقط
        └── الحماية غير متاحة على هذه النسخة
```

## Screen 1 — Explain before requesting

**Header:** `حماية رقمية مناسبة لعائلتك`

**Body:** `يحتاج 3ialna إلى إذن الرقابة من Apple حتى يطبّق القيود التي تختارها أنت. لا نقرأ الرسائل أو الصور، ولا نعرض محتوى الصفحات داخل لوحة الوالد.`

**Privacy points:**

- `تتحكم أنت في التطبيقات والفئات التي تريد تقييدها.`
- `يمكنك إيقاف القيود من لوحة الرقابة.`
- `تظهر حالة الحماية بوضوح؛ لن نقول إن الحماية تعمل إذا كان الامتداد متوقفاً.`

**Primary action:** `متابعة`

**Secondary action:** `لاحقاً`

## Screen 2 — Request Family Controls authorization

**Header:** `منح إذن الرقابة`

**Body:** `سيظهر الآن طلب من Apple. اختر السماح حتى يتمكن 3ialna من تطبيق سياسة العائلة على هذا الجهاز أو ملف الطفل.`

**Primary action:** `منح الإذن`

**Error:** `تعذر الحصول على إذن الرقابة. تحقق من إعدادات Screen Time أو حاول مرة أخرى.`

**Denied state:** `لم يتم منح الإذن. يمكنك المتابعة إلى لوحة الرقابة، لكن قيود التطبيقات لن تعمل حتى تمنح الإذن.`

## Screen 3 — Choose protection scope

**Header:** `اختر ما تريد حمايته`

**Sections:**

| Section | Arabic label | Explanation |
|---|---|---|
| App controls | `قيود التطبيقات والفئات` | `حدد التطبيقات أو الفئات التي تحتاج إلى حدود أو حظر.` |
| Domain policy | `حماية النطاقات` | `طبّق سياسة النطاقات المحظورة والمسموح بها على مسار الويب المدعوم.` |
| Schedules | `الجداول الزمنية` | `حدد أوقات الدراسة والنوم والراحة.` |

**Primary action:** `حفظ السياسة`

**Empty state:** `لم تختر قيوداً بعد. يمكنك بدء الحماية بإضافة فئة أو نطاق.`

## Screen 4 — Confirm real enforcement

**Active:**

- Headline: `الحماية مفعّلة`
- Detail: `تم منح الإذن، وتعمل طبقة الحماية المحددة على الجهاز.`
- Action: `مراجعة السياسة`

**Authorized only:**

- Headline: `تم منح إذن الرقابة`
- Detail: `إذن Screen Time متاح، لكن حماية الويب تحتاج إلى امتداد Network Extension مفعّلاً.`
- Action: `عرض المتطلبات`

**Unsupported:**

- Headline: `الحماية غير متاحة على هذه النسخة`
- Detail: `تحتاج هذه الميزة إلى iOS وامتدادات Apple معتمدة. يمكنك استخدام إعدادات التطبيقات المتاحة.`
- Action: `فهم المتطلبات`

**Error:**

- Headline: `تعذر التحقق من حالة الحماية`
- Detail: `لم نتمكن من تأكيد حالة الامتداد. لن نعرض الحماية على أنها مفعّلة حتى يتم التحقق.`
- Action: `إعادة المحاولة`

## Layout wireframe

```text
┌────────────────────────────────────────────┐
│ ←                              3ialna      │
│                                            │
│              حماية رقمية مناسبة لعائلتك    │
│                                            │
│  ●  لماذا نحتاج الإذن؟                     │
│     شرح الخصوصية وحدود الحماية             │
│                                            │
│  ●  منح إذن الرقابة                        │
│     طلب Apple الرسمي                       │
│                                            │
│  ●  اختيار الحماية                         │
│     التطبيقات · النطاقات · الجداول         │
│                                            │
│  ────────────────────────────────────────  │
│  [متابعة]                                  │
│  لاحقاً                                    │
└────────────────────────────────────────────┘
```

Use native RTL layout, dynamic type, VoiceOver labels, and a visible back action. Do not hide the system authorization purpose behind a generic “enable” label.
